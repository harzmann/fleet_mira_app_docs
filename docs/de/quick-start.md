# Schnellstart

## Erster USB-Download

1. Prüfen Sie, dass Adapter, Kabel und Fahrtenschreiber zusammenpassen und die erforderliche Zugangs- beziehungsweise Fahrerkarte eingelegt ist.
2. Verbinden Sie Android über OTG und einen echten USB-RS-232-Adapter mit dem Fahrtenschreiber.
3. Öffnen Sie **Download**. Prüfen Sie Anschlussstatus und ausgewählten Adapter.
4. Wählen Sie zunächst **Fahrzeug kompakt** oder ein für Ihre Aufgabe freigegebenes Profil.
5. Tippen Sie **Download starten** und bestätigen Sie Androids USB-Freigabe.
6. Lassen Sie die Verbindung bis zum Abschluss bestehen. **Download abbrechen** beendet den Versuch bei Bedarf.
7. Öffnen Sie **Verlauf**, klappen Sie den Vorgang auf und prüfen Sie Ergebnis und vollständige Dateien.
8. Exportieren oder übertragen Sie wichtige Originaldateien. Prüfen Sie Übertragungsstatus separat vom Downloadstatus.

Ist der Startbutton deaktiviert, fehlt meist ein ausgewählter geeigneter USB-Adapter oder ein Profil. Das Öffnen der App allein startet keinen Download.

## Ohne USB beginnen

- **DLTNG vorhanden:** Unter **Einstellungen → DLTNG-Dateiquellen** eine Quelle anlegen; anschließend unter **Download → Dateien vom DLTNG** Dateien laden und auswählen.
- **Fleet Mira vorhanden:** Unter **Einstellungen → Übertragungsziele** den Server einrichten und bei Bedarf im Browser anmelden. Unter **Hauptserver und Erinnerungen** diesen Server für den Fuhrpark auswählen und abgleichen.
- **Oberfläche ansehen:** Die Hauptbereiche lassen sich ohne Zugang öffnen. Leere Ansichten erklären, welche Daten oder Verbindungen fehlen.
