# Export, E-Mail und Sicherung

## Originaldatei exportieren

Öffnen Sie **Verlauf**, klappen Sie den Vorgang auf und wählen Sie bei einer vollständigen Datei **Exportieren**. Androids Dateiauswahl bestimmt den Speicherort. Die Originaldatei in der App bleibt erhalten. Prüfen Sie anschließend, dass die exportierte Kopie am gewählten Ziel vorhanden und vollständig ist.

Ein Export sichert die ausgewählte Originaldatei, nicht automatisch Profile, Zugangsdaten, sämtliche Verlaufseinträge oder den gesamten App-Speicher.

## An einen Server senden

**Senden** öffnet die Zielauswahl. Wählen Sie ein aktives eingerichtetes Ziel. Die dauerhafte Übertragung kann auf WLAN oder auf das Ende einer USB-Sitzung warten. Der Serverstatus im Verlauf zeigt, ob nur Empfang oder bereits der endgültige Ziel-/Importzustand bestätigt wurde. Bei **Korrektur erforderlich** beheben Sie den angezeigten Grund und versuchen die Übertragung erneut.

## An eine Mail-App übergeben

1. Öffnen Sie **Einstellungen → Anhänge auswählen** oder die E-Mail-Aktion eines aufgeklappten Vorgangs.
2. Markieren Sie eine oder mehrere vollständige Dateien. Anzahl und Gesamtgröße werden angezeigt.
3. Wählen Sie **An Mail-App übergeben**.
4. Wählen Sie im Android-Dialog eine geeignete Mail-App. Prüfen Sie dort Empfänger und Anhänge und entscheiden Sie dort über den Versand.

Es sind höchstens 100 Anhänge pro Übergabe möglich; die Mail-App kann geringere Größen-/Anzahlgrenzen haben. Die App verwendet keine eigene SMTP-Verbindung. Eine Übergabe oder ein Eintrag in **Letzte Übergaben** ist kein Versand- oder Zustellbeleg. **Abbrechen** im Android-Dialog versendet nichts.

## Vor Gerätewechsel oder Deinstallation

Exportieren oder übertragen Sie alle benötigten vollständigen Originaldateien. Prüfen Sie die Kopien beziehungsweise den bestätigten Archivimport unabhängig am Ziel. Notieren Sie erforderliche Einstellungen nach Ihrer betrieblichen Vorgabe; Zugänge für das neue Gerät erhalten Sie vom Administrator. Android-Cloudsicherung ist deaktiviert. Löschen Sie den App-Speicher nicht, bevor Ihre Sicherung überprüft ist.
