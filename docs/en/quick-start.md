# Quick start

## Your first USB download

1. Check that adapter, cable and tachograph are compatible and the required access or driver card is inserted.
2. Connect Android to the tachograph through OTG and a real USB-RS-232 adapter.
3. Open **Download**. Check connection status and the selected adapter.
4. Start with **Fahrzeug kompakt** (compact vehicle) or a profile approved for your task.
5. Tap **Download starten** and confirm Android's USB permission.
6. Keep the connection attached until completion. **Download abbrechen** cancels the attempt if necessary.
7. Open **Verlauf**, expand the entry and check the result and complete files.
8. Export or transfer important originals. Check transfer status separately from download status.

A disabled start button usually means a suitable USB adapter or profile has not been selected. Opening the app does not itself start a download.

## Start without USB

- **You have a DLTNG:** Add a source under **Einstellungen → DLTNG-Dateiquellen**, then load and select files under **Download → Dateien vom DLTNG**.
- **You have Fleet Mira:** Configure a target under **Einstellungen → Übertragungsziele** and sign in through the browser if needed. Select that server under **Hauptserver und Erinnerungen** and refresh the fleet.
- **Explore the interface:** You can open the main areas without an account. Empty states explain what data or connections are missing.

See [USB downloads](download.md), [DLTNG](dltng.md), [fleet](fleet.md) and [troubleshooting](troubleshooting.md) for details.
