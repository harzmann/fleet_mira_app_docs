# Version and limitations

## 0.6.0-dev – 9 November 2026

- New product name **Fleet Mira App**, previously **DTCO Download Android**.
- The name appears in the launcher, app toolbar and download notifications.
- Android identifier, file provider, OAuth callback and existing local data are retained for compatible updates. The same signing key is still required.
- Public German/English manual using the established Fleet Mira documentation design.
- Blue Material 3 interface with persistent light/dark/system selection and adaptive phone/tablet navigation.

## Evidence versus approval

Builds, unit tests and emulator views demonstrate the corresponding software state. They do not qualify your real Android, adapter, cable, tachograph and server combination. A development APK and published documentation are not blanket production approval.

Screenshots use synthetic demonstration data. Data ages, registrations, people and check results are examples, not real customer records or valid signature evidence.

## Not offered as released capabilities

Direct Bluetooth downloads, automatic driving-licence authenticity verification, qualified automatic country/card-model identification and full translation of the download/settings interface. The app does not calculate its own statutory deadlines or live remaining driving times.

The current APK is explicitly published as a [debug-signed GitHub prerelease](https://github.com/harzmann/fleet_mira_app_docs/releases/tag/v0.6.0-dev). [Installation](installation.md) provides the download and SHA-256 checksum. Future documentation changes do not automatically publish new APKs.
