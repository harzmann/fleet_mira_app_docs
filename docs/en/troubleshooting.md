# Troubleshooting

| Observation | Check and continue |
|---|---|
| **Download starten** is disabled | Attach a suitable USB adapter and select adapter and profile. Check OTG/USB host and real RS-232 rather than TTL. |
| Android USB permission refused | Reattach the adapter and deliberately grant access. Existing files remain unchanged. |
| Interrupted download or partial file | Check connection, power, cable, card arrangement and notices. Start a new attempt; share complete files only. |
| History results missing | Open filters, reset the draft and choose **Anwenden**. Indexing may pause during USB. |
| Incorrect VIN or unknown identity | Do not guess associations. Check original data, cards and vehicles; resolve conflicts with the responsible person. |
| Delivery remains queued | Check Wi-Fi/mobile permissions, reachability, active USB session and the individual target state. |
| Server received but did not import | Wait for full processing confirmation or ask for server-side investigation. Do not treat receipt as confirmed archive import. |
| HTTPS/certificate error | Ask IT to verify server name, validity and certificate chain. Do not bypass verification. |
| DLTNG file list cannot load | Check file listener, address, port and device API key. Upload target and file source are separate configurations. |
| Fleet Mira sign-in missing or expired | Restart browser sign-in. Ask the administrator about permissions and API compatibility. |
| Fleet snapshot is old | Check data age and refresh. Offline, only the saved snapshot is available. |
| No reminder | Check primary-server reminder settings, Android notifications and a sufficiently fresh server snapshot. Android may delay background work. |
| Email handoff fails | Check complete files and a suitable email app; reduce count/size. Handoff is not proof of sending. |
| NFC check unavailable | Enable NFC; check registered chip, connectivity and personal permissions. |
| Image evidence not assessable | Capture sharp, well-lit front/back images and follow the reasoned review decision. OCR does not prove authenticity. |

## Information for support

Record app version from **Diagnose**, Android version, device model, time, exact error and affected feature. For USB, add adapter, cable and tachograph model. Do not share passwords, tokens or raw data in public issues. Use the agreed protected support channel for sensitive evidence; see [privacy](privacy.md).
