# History and filters

**Verlauf** groups local sessions and existing files. Cards show registration or driver, date, VIN, time, data types, download state and transfer state. Unknown identity information remains unknown.

## Details and originals

Tap an entry or **Details anzeigen**. Expanded details include profile, data types, driver information, original files and individual transfers. **Fahrzeuginformation** distinguishes the snapshot taken at that download from the current vehicle record. Tap again to collapse details.

Complete files offer **Exportieren**, **Senden** and, where available, **Dateien per E-Mail übergeben**. Returning from a detail page keeps the entry expanded.

## Search and filter

The top-right icon opens **Suchen und filtern**. Search registration, VIN, first/last names and card number. Restrict dates, data types, delivery routes, download state and server transfer state. Multiple search words must match within the same session. Date limits include both days.

- **Anwenden:** apply the draft; the icon badge indicates active filters.
- **Abbrechen:** discard draft changes.
- **Zurücksetzen:** reset the draft only; apply afterwards to activate it.

Selections survive navigation and rotation. A new launch starts with the default selection. The result count distinguishes missing files from a filter hiding all entries.

## Read status

| Display | Meaning |
|---|---|
| **Abgeschlossen** for a download | Local download is complete |
| **Mit Einschränkungen / Fehlgeschlagen** | Check notices and individual file results |
| **Lokal** | No server job for this session |
| **Vorgemerkt / Wiederholung geplant** | Delivery is waiting or scheduled to retry |
| **Auf Server empfangen / Wird verarbeitet** | Receipt or processing, without full business confirmation yet |
| **Archiviert / Ziel bestätigt** | The server confirmed that terminal state |
| **Korrektur erforderlich** | Check credentials, target or the displayed error |

A failed signature-check indication is not proof of authenticity. Originals remain unchanged. Search metadata is supplemented in the background; this can pause during USB sessions without turning a successful download into a failure.
