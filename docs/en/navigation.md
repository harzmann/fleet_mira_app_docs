# Navigation and appearance

| Main area | Purpose |
|---|---|
| **Download** | USB connection, profile, download start and DLTNG retrieval |
| **Verlauf** | Local history, original files, search, filters and transfers |
| **Fuhrpark** | Local vehicles and authorised Fleet Mira data |
| **Profile** | Recurring download selections and transfer targets |
| **Einstellungen** | Appearance, servers, file sources, licence checks and diagnostics |

On phones, navigation is at the bottom; the final item is labelled **Optionen**. Sufficiently large windows use side navigation. Large text uses a fully labelled destination selector. Tablets show download configuration and status alongside each other when space permits.

## Light, dark or system

Under **Einstellungen → Darstellung**, choose **System** (follow Android), **Hell** (light surfaces) or **Dunkel** (dark surfaces). Changes apply immediately and survive app restarts. The blue colour scheme does not depend on wallpaper. Changing this website's colour mode does not change the app setting.

## Back and actions

The toolbar arrow or Android Back returns to the calling page. **Speichern** saves a form; **Abbrechen** discards its changes. Tap an expanded history entry again to collapse it. Icons supplement labels; important states also have text.

The main download/settings interface is not yet fully translated into every planned language. This manual quotes the German labels used by that interface. After sign-in, mobile licence checks use the profile language and region supplied by the server.
