# Fleet Mira App

The mobile companion for tachograph data, fleet information and driving-licence checks on Android phones and tablets. Fleet Mira App combines USB downloads and locally stored original files with compatible DLTNG and Fleet Mira services.

!!! info "Documented version"

This is a development build; obtain installation packages and operational approval through your organisation's distribution channel. This site does not offer a public app-store download.
